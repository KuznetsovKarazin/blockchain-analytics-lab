Популяции для ограниченного replay: определения от 25 октября 2026

1. Euler V1: все logs emitter 0x27182842e098f60e3d576794a5bffb0777e025d3 за [2023-03-01, 2023-03-02) UTC, без topic-фильтра. Источник адреса — addresses/euler-addresses-mainnet.json, root key euler, commit dfaa7788b17ac7c2a826a3ed242d7181998a778f. Вложенные modules — implementation addresses, ими нельзя заменять core emitter. Euler.dispatch выполняет delegatecall; ERC20 Transfer/Approval могут отдельно выпускаться от eToken/dToken proxy.

Это популяция событий ядра, не все транзакции/вызовы протокола. Начальный допустимый detector — event-count/rate. Core Withdraw охватывает внутренние уменьшения и переносы баланса, включая donateToReserves; его сумму нельзя считать внешним token outflow или потерями. Для реального движения underlying assets нужны полные receipts, ERC20 Transfer и корректные единицы токенов. RequestDonate/Liquidation сами по себе не доказывают выполнение или пропуск проверки платёжеспособности.

2. Beanstalk: альтернативный день [2022-04-01, 2022-04-02) UTC, все logs Diamond 0xc1e088fc1323b20bcbee9bd1b9fc9546db5624c5. Исторический source commit e0cf6b8dd7dbeacc809eda475f9bb1d6197b748b подтверждает адрес в readme.md и test constants. Старый BEAN — 0xdc59ac4fefa32293a95889dc396682858d52e5db; современный BEAN 0xBEA... к этому периоду не относится.

До инцидента найден другой source snapshot e9f49910e287e7a7afaa6db8f536b7194728b0af. В VoteList индексирование uint32[] bips изменяется с indexed на non-indexed: topic0 остаётся тем же, layout/восстановимость меняются. ABI нельзя выбирать только по сигнатуре события. Требуется история DiamondCut и фактическая привязка selector→facet по блокам/порядку исполнения. Proposal не содержит init/facet payload; Commit не различает normal/emergencyCommit. Для этих интерпретаций нужны input/call traces и исторический код/состояние.

3. Границы доказательств. Commit timestamp и совпавший hash исходника не доказывают, что именно этот bytecode/ABI был установлен в выбранный день. Для Euler восстановить InstallerInstallModule и moduleGitCommit; для Beanstalk — DiamondCut/facets. До этого all-topic event-count replay можно выполнять в явно ограниченной популяции. Для границ дня использовать реальные block timestamps, не средний интервал между блоками. Сохранять неизвестные historical observed_time=null. День без известной атаки не объявлять безопасным.

4. Previous exposure. Scoped audit в ../exposure_audit_20261025.json: Euler и Beanstalk — L2 (S2 каталог/курация K4 exclusion, у Euler также whole-chain M1); BSC Token Hub — L0 только в проверенной области. Положительное targeted использование данных этих атак в трёх проверенных K4 runs не найдено; обычные фоновые взаимодействия с протоколами в бинарных K4 tables полностью не проверены. Ни один случай не объявлен независимым eligible тестом. Для Beanstalk историческая дата каталога 2022-04-16 не заменяет attack day 2022-04-17; proposal и theft labels должны оставаться раздельными.

5. Source provenance. source_provenance_20261025.json содержит первичные pinned URL, Git blob SHA и SHA-256 для 15 точно проверенных файлов. Полные vendor sources не включены сюда; пути source_snapshots относятся к частному evidence package candidate_population/. Euler исходники имеют GPL-2.0-or-later, Beanstalk — MIT. При повторном получении сверять байты с обоими хешами. Configs содержат определения популяций, а не текущий статус acquisition; фактические данные/покрытие/ошибки брать из отдельных run manifests.
